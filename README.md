# 仓鼠AI（Hamster AI）

当前源码版本：**1.7.5 · 仓鼠AI本地版**。本仓库不包含个人 API Key、任务数据、素材库、生成结果、Python 虚拟环境和桌面安装包。

应用统一通过「工作台」打开浏览器，在仓鼠智能体、智能成片和创意工作台之间切换；账户页一次配置共享智能 Key 与推理接入点。模型理解只使用视频、图片和文本，不提取或独立上传音轨。参见 [统一入口](docs/workbench-1.7.4.md)、[共享接入点](docs/shared-endpoint.md) 和 [1.7.5 输入能力说明](docs/visual-input-1.7.5.md)。

新增 **仓鼠AI智能体**：多模态连续聊天、图片/视频/PDF/文档输入、资产选择及本地会话保存。复用独立工作台服务，使用与数据边界见 [智能体 V1](docs/hamster-chat.md)。

启动失败时可在弹窗或「账户 → 启动诊断」一键导出脱敏日志。客户操作与保留策略见 [启动诊断](docs/startup-diagnostics.md)。

主应用任务从提交起保存在本地服务的 `task-history` 目录；重启自动按任务 ID 恢复查询，结果保存到桌面后使用本地文件预览。完整规则与边界见 [任务生命周期](docs/task-lifecycle.md)。完全退出期间暂停本地轮询，重新打开后恢复；不会自动重复提交付费任务。

本地运行的 AI 生成客户端，直连两个上游服务，填入 API Key 即可使用：

- **图片 / 视频生成** — AI 文生图 / 文生视频
- **数字人** — 人物参考图 + 音频 → 口型同步视频
- **工具箱 · 黑白深度视频** — 普通视频 → 黑白深度视频
- **创意工作台** — 视频理解、脚本拆解、素材替换与参考提示词，独立 localhost 页面
- **智能成片** — 从桌面应用启动独立的 VeADK 本地工作台

## 快速开始

要求：Node.js ≥ 18（本机已装即可）。

```bash
npm ci
node server.js
# 或
npm start
```

启动后自动打开浏览器（默认 http://localhost:8787）。

## 桌面版（Electron）

**便携版 exe（构建后免安装、免 Node）**

执行 `npm run runtime:build`、`npm run dist` 后双击 `dist/仓鼠AI-1.7.2-便携版.exe`。源码仓库不提交 `dist/`；发布安装包时应单独使用仓库 Releases。详见 [离线运行环境与服务管理](docs/portable-runtime.md)。

主程序会启动内置本地服务并打开桌面窗口；首次打开工作台会解压并校验内置 Python 和固定依赖，可能需要几分钟，后续复用本地缓存，不需要联网安装。配置、任务和资产不放在临时解压目录，删除 EXE 不会删除它们。

**开发 / 重新打包**

```bash
npm run electron    # 开发模式启动桌面应用
npm run runtime:build # 在 Windows x64 构建固定依赖的离线 Python 包（仅开发机联网）
npm run dist        # 重新打包便携版 exe（输出到 dist/）
python tools/make-icon.py   # 重新生成应用图标 build/icon.ico
```

## 智能成片（V1）

“智能成片”使用独立的中文本地工作台，底层运行官方 `ad_video_gen_seq` 串行工作流。源码、页面和启动器均随应用打包，启动时自动更新到可写用户目录。开发时可指定另一份包含 `web.py`、`studio.py` 和 `studio-ui` 的适配工作流：

```powershell
$env:HAMSTER_SMART_VIDEO_DIR = 'C:\path\to\agentkit-samples\python\02-use-cases\ad_video_gen_seq'
npm run electron
```

点击“智能成片”会优先使用本机 8000 端口，被占用或受限时自动选择其他空闲端口；浏览器在服务身份、版本和健康检查通过后打开实际地址。便携版内置 Python、固定依赖与 FFmpeg，不调用客户电脑的 Python 或 uv。工作台包含商品需求、参考素材、七阶段进度、候选素材预览、成片下载和历史任务。固定四个分镜，目标时长约20秒或40秒；每镜可选1组或2组图片/视频候选。实际生成时长、质量和费用由上游与模型执行结果决定。

图片/视频与素材上传复用三宝 Key；策划和评估使用火山方舟 Key。页面动态读取账户配置，无需重新安装。最终文件保存在桌面 `仓鼠AI生成结果/智能成片`，任务记录在工作流目录 `studio-data`。只有生成本地文件才报告完成；服务重启会标记未完成任务为中断，停止流程不会撤销上游已提交的收费任务。

官方联网调研工具另外要求火山引擎 AK/SK。未配置这组凭据时，工作台根据商品信息和通用营销知识完成策划，不调用联网检索，也不声称获得实时市场数据。

开发调试：在 `smart-video-agent` 目录执行 `.venv/Scripts/python.exe web.py`。离线验证执行 `python -m unittest test_studio -v`；不会请求付费模型。原 VeADK 开发页面仍可用 `veadk web agents` 手动运行，客户入口为中文工作台。

> 注意：若终端里设了 `ELECTRON_RUN_AS_NODE` 环境变量会异常，需先 `unset ELECTRON_RUN_AS_NODE`（正常环境无需理会）。
> 国内网络打包慢时，先设置镜像：`ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR` 指向 npmmirror。

## 使用步骤

1. 左侧「账户」→ 填入 API Key
   - 图片/视频 API Key → 图片/视频生成
   - RunningHub API Key（32 位）→ 数字人与工具箱共用
2. **生成**：输入提示词、上传参考素材（图/视频/音频/链接，提示词可用 `@图片1` 引用）、选模型/比例/时长 → 发送
3. **数字人**：上传人物参考图 + 音频（≤30 秒）→ 生成数字人视频
4. **工具箱 · 黑白深度视频**：上传源视频 → 生成深度视频
5. **创意工作台**：上传参考视频 → 拆解脚本、选择素材并生成参考提示词
6. 媒体结果会自动保存到桌面的 `仓鼠AI生成结果` 文件夹；生成记录和反推文本可在「历史」页查看

## 说明

### 1.3.0 本地资产与达人带货工作台

- 应用启动后自动创建桌面的 `仓鼠AI资产库/达人`、`产品`、`场景` 三个文件夹。通过应用导入图片/视频，文件复制入库，原文件不动；不需要额外对象存储。
- 侧栏「达人资产」可分类、搜索、预览和选择素材；资产包含本地文件及配套 JSON 记录，备份时请一起保留。当前支持 PNG/JPG/WebP（最多30MB）、MP4/WebM/MOV（最多50MB）。
- 智能成片现在是 AI 达人带货工作台：达人、产品、场景各选一份资产或临时图片/视频；补充产品图片入口继续保留。三类新选择位在开始制作时才上传，每次获得新的临时 URL；临时素材不自动入库。
- 图片负责达人形象、产品外观、场景环境。视频作为动作、节奏及运镜参考直接传到视频 API。参考是生成约束，不保证完全复刻或绝对一致。只使用有权使用的人物和商品素材。
- 已自动保存的图片/视频结果在任务卡和历史页有「收入资产库」按钮。智能成片完成后也可选择分类入库；仅复制本地成片，不依赖过期的结果链接。
- 工作台通过主应用的本地资产服务共享文件，使用时保持仓鼠AI应用开启。工作台重启后仍可选取资产，但复用历史任务时需要重新选择素材，不复用旧临时 URL。
- 余额及积分消耗徽标不展示。视频保留 MinimaxH3、WAN3.0、seedance2.0、seedance2.5；seedance2.5 线路仅支持图片参考。图片仅保留 Image 2.5 Flare / Sunburst。显示名称与实际请求 ID 分开管理。
- 离线验证：`npm test`、工作流目录 `python -m unittest test_studio -q`；`scripts/qa-assets.js` 用于浏览器资产流程回归，生成接口使用模拟响应，不产生付费任务。

- 两个 API Key 都保存在浏览器 localStorage（可选同时持久化到本地 `config.json`），只发往对应上游
- 本地服务为透明代理，密钥只发往对应的云端接口；模型列表走公共端点（无需 Key）
- 生成结果临时链接以接口返回有效期为准；主应用自动查询和保存，保存成功后的本地预览不依赖临时链接
- 生成页支持直接拖入图片、视频、音频；数字人页的图片和音频框也支持拖放
- 数字人和深度任务使用工具 Key；普通图片/视频使用生成 Key，智能成片/创意工作台另需智能模型 Key
- 端口可用环境变量 `PORT` 覆盖：`PORT=9999 node server.js`

## UI 组件与动画

- `Lucide`：统一导航、素材、生成参数、下载和账户操作图标
- `AutoAnimate`：处理素材列表、任务流、数字人/工具箱结果和历史记录的增删位移动画
- 组件运行文件与许可证保存在 `public/vendor/`，桌面版离线运行，不依赖 CDN
- CSS 负责悬停、按下、聚焦、上传、进度和结果状态；系统开启“减少动态效果”时会自动停用非必要动画
