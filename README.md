# 仓鼠AI（Hamster AI）

当前正式版本：**1.7.49**。官方网站：[hamsterai.cc](https://hamsterai.cc)，[下载便携版](https://hamsterai.cc/download/HamsterAI-Portable-1.7.49.exe)。2026-10-18 按用户指令发布现有封包，线上完整文件 SHA-256 与本地一致。本轮修复任务安全、规格合同、账户管理与对话隔离；最终功能、真实计费和安装升级验收仍由人工执行。官网发布记录见 [1.7.49 发布与清理](docs/release-1.7.49-20261018.md)。Git 不收录个人 API Key、任务数据、素材库、生成结果、Python 虚拟环境和桌面发行包。

账户使用同一 PIKNO 账户的图片 Key、视频 Key、工具 Key，共用余额。数字人与黑白深度共用工具 Key；新工具任务不再使用视频 Key，同账户有对应权限的有效 Key 仍可恢复历史任务。Key 在发布版由系统加密保护，不回显、不保存到浏览器；开发模式仅进程内保存。

「对话」打开独立聊天页面，保留图片、最长3分钟视频、文档附件、资产引用和本地会话。独立反推改写工作台已退役，旧创意数据与导出结果保留。对话沿用图片／视频 Key 授权；连接是否可用须单独云端检测，工具 Key 不扩大对话权限。

创作画布保留现有节点与交互，逐节点手动执行；按目标功能分别使用图片、视频或工具授权。节点完成后先保存本地结果并生成 Output，下游执行时重新取得素材授权。未知结果只恢复原任务，不自动重发。工程基线见 [1.7.47 需求确认](docs/refactor-1.7.47-requirements.md)。

生成页、图片编辑、数字人、黑白深度及画布采用 PIKNO 已发布线路名，展示客户单价、单位与本次预计费用，确认后才提交。报价由 PIKNO 服务端统一计算；缺价、过期、参数改变或改价需要重新报价确认。历史任务保留原名称和报价快照。2026-10-18 公开只读核验 PIKNO 已有报价协议；旧目录缺少素材总量字段时按20兼容。本次未部署配套 PIKNO／推理网关，对话保持“尚未开放”。实施、回退和人工验收见 [1.7.49 修复交付](docs/full-adaptation-1.7.49.md)。

**仓鼠AI对话**保留多模态连续聊天、图片／视频／PDF／文档输入、资产引用和本地会话保存。使用独立聊天服务；生产智能服务尚未开放时明确提示，不要求反复更换 Key。使用与数据边界见 [对话说明](docs/hamster-chat.md)。

1.7.39 起，异常默认在后台自动脱敏反馈，无需手动导出或首次授权弹窗；账户页保留折叠隐私说明。范围与保留策略见 [故障反馈](docs/startup-diagnostics.md)。

主应用任务从提交起保存在本地服务的 `task-history` 目录；重启自动按任务 ID 恢复查询，结果保存到桌面后使用本地文件预览。完整规则与边界见 [任务生命周期](docs/task-lifecycle.md)。完全退出期间暂停本地轮询，重新打开后恢复；不会自动重复提交付费任务。

本地运行的 AI 生成客户端，按业务线路填写 API Key 即可使用：

- **图片 / 视频生成** — AI 文生图 / 文生视频
- **数字人** — 人物参考图 + 音频 → 口型同步视频
- **工具箱 · 黑白深度视频** — 普通视频 → 黑白深度视频
- **对话与创作画布** — 多模态对话、素材引用、节点创作与本地结果复用

## 快速开始

要求：Node.js ≥ 18（本机已装即可）。

```bash
npm ci
node server.js
# 或
npm start
```

启动后自动打开浏览器（默认 http://localhost:8787）。

## 桌面版（Electron）

**便携版 exe（构建后免安装、免 Node）**

本次正式文件在 `dist/release-1.7.49/`，本地回退包在 `dist/rollback-1.7.46/`。执行 `npm run runtime:build`、`npm run dist` 可重新构建。源码仓库不提交 `dist/`；官网仅提供便携版，安装版仅本地保留。详见 [离线运行环境与服务管理](docs/portable-runtime.md) 和 [官网部署记录](docs/official-website.md)。

主程序会启动内置本地服务并打开桌面窗口；首次打开对话会解压并校验内置 Python 和固定依赖，可能需要几分钟，后续复用本地缓存，不需要联网安装。配置、任务和资产不放在临时解压目录，删除 EXE 不会删除它们。

**开发 / 重新打包**

```bash
npm run electron    # 开发模式启动桌面应用
npm run runtime:build # 在 Windows x64 构建固定依赖的离线 Python 包（仅开发机联网）
npm run dist        # 重新打包便携版 exe（输出到 dist/）
python tools/make-icon.py   # 重新生成应用图标 build/icon.ico
```

> 注意：若终端里设了 `ELECTRON_RUN_AS_NODE` 环境变量会异常，需先 `unset ELECTRON_RUN_AS_NODE`（正常环境无需理会）。
> 国内网络打包慢时，先设置镜像：`ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR` 指向 npmmirror。

## 使用步骤

1. 在 PIKNO 注册、充值并创建同账户的图片 Key、视频 Key、工具 Key，返回「账户」填写并免费检测。至少配置一个；空白保留已存 Key，也可勾选单项移除。对话连接仍需单独检测。
2. **生成**：输入提示词、上传参考素材（图/视频/音频/链接，提示词可用 `@图片1` 引用）、选线路／规格／份数 → 获取报价 → 确认费用后发送
3. **数字人**：确认工具可用 → 上传人物参考图 + 音频（≤30 秒）→ 确认报价 → 生成数字人视频
4. **工具箱 · 黑白深度视频**：确认工具可用 → 上传源视频 → 确认报价 → 生成深度视频
5. **对话／创作画布**：聊天理解附件，或通过素材、提示词和生成节点逐步创作；画布不会自动执行下游节点。
6. 媒体结果保存到桌面的 `仓鼠AI生成结果` 文件夹；生成记录可在「历史」页查看。旧创意记录和已导出文本保留在原目录。

新版操作详见 [三 Key 与报价教程](website/public/tutorials/1.7.49/index.html)。1.7.46 双 Key 与工作台流程保留在 [版本归档](website/public/tutorials/1.7.46/index.html)，不适用于新版。

批量可停止尚未发送份数；已发送任务继续查询。清理记录保留未知任务，保存失败不会触发重新生成。当前单图线路仅支持文字编辑；圈选在真实协议与效果验收前不可用。

## 历史版本说明（旧接入流程以顶部当前基线为准）

### 1.3.0 本地资产与达人带货工作台

- 应用启动后自动创建桌面的 `仓鼠AI资产库/达人`、`产品`、`场景` 三个文件夹。通过应用导入图片/视频，文件复制入库，原文件不动；不需要额外对象存储。
- 侧栏「达人资产」可分类、搜索、预览和选择素材；资产包含本地文件及配套 JSON 记录，备份时请一起保留。当前支持 PNG/JPG/WebP（最多30MB）、MP4/WebM/MOV（最多50MB）。
- 图片负责达人形象、产品外观、场景环境。视频作为动作、节奏及运镜参考直接传到视频 API。参考是生成约束，不保证完全复刻或绝对一致。只使用有权使用的人物和商品素材。
- 已自动保存的图片/视频结果在任务卡和历史页有「收入资产库」按钮；仅复制本地文件，不依赖过期的结果链接。
- 工作台通过主应用的本地资产服务共享文件，使用时保持仓鼠AI应用开启。工作台重启后仍可选取资产，但复用历史任务时需要重新选择素材，不复用旧临时 URL。
- 余额及积分消耗徽标不展示。视频仅保留 SD2.5-按次-720P、SD2.5-按次-线路3、SD2.5-9图-30秒三条线路，分别标注 15元/次、15元/次、6元/次；第三条仅支持 9 张图片参考和固定 30 秒。图片线路保持不变。显示名称与实际请求 ID 分开管理。
- 生成类型菜单提供“视频生成（主线路）”与“官方视频生成（备选线路）”；备选线路仅开放480P，标价0.55元/秒，最多支持9图、3视频、3音频，本地素材统一通过临时对象存储转存。用户界面不得显示第三方供应商、上游模型或存储服务名称。
- 离线验证：`npm test`、工作流目录 `python -m unittest test_studio -q`；`scripts/qa-assets.js` 用于浏览器资产流程回归，生成接口使用模拟响应，不产生付费任务。

- 业务 API Key 保存在浏览器 localStorage（可选同时持久化到本地 `config.json`），只发往对应服务；共享推理密钥和接入点不进入客户端
- 本地服务为透明代理，密钥只发往对应的云端接口；模型列表走公共端点（无需 Key）
- 生成结果临时链接以接口返回有效期为准；主应用自动查询和保存，保存成功后的本地预览不依赖临时链接
- 生成页支持直接拖入图片、视频、音频；数字人页的图片和音频框也支持拖放
- 生成页素材使用端到端流式上传：图片发送至主线路，视频/音频发送至临时对象存储，不再在浏览器和本地服务中各复制一份完整文件；界面显示实时百分比、速度和预计剩余时间，同一批次的重复素材复用上传结果
- 图片、视频、数字人和深度视频在本地校验并持久化后立即显示“已提交”；上游创建与任务轮询在后台继续，慢请求不会锁住下一次提交，刷新页面会从本地任务日志恢复
- 页面更新改为按素材/任务键复用已有节点：上传进度只刷新对应素材，任务流和历史首屏各显示 40 条、资产库首屏显示 48 条并可分批加载；图片延迟解码、视频不再预加载媒体正文，减少长列表的全量重绘和内存占用
- 启动配置与资产摘要合并读取；模型列表缓存 6 小时，更换 Key 后立即失效；资产索引缓存 5 分钟且写入后主动失效；同类 GET 请求自动合并，R2 状态成功时降频、失败时渐进重试
- 数字人和深度任务使用工具 Key；普通图片/视频使用生成 Key，创意工作台另需智能模型 Key
- 端口可用环境变量 `PORT` 覆盖：`PORT=9999 node server.js`

## UI 组件与动画

- `Lucide`：统一导航、素材、生成参数、下载和账户操作图标
- `AutoAnimate`：处理素材列表、任务流、数字人/工具箱结果和历史记录的增删位移动画
- 组件运行文件与许可证保存在 `public/vendor/`，桌面版离线运行，不依赖 CDN
- CSS 负责悬停、按下、聚焦、上传、进度和结果状态；系统开启“减少动态效果”时会自动停用非必要动画
