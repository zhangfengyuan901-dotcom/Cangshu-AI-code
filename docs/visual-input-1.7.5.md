# 1.7.5 · 仅使用视频、图片、文本理解

本版本覆盖之前文档中的音画联合模式说明：统一智能接入点不再接收独立音频输入。

- 聊天与创意工作台不再提取、解码或单独上传音轨，视频检查使用 `VideoFileClip(audio=False)`。上传的是原视频文件，不另行转码去除其中已有的声音流。
- 创意工作台移除分析模式选择，只分析画面与可见字幕；不能把字幕当成已经核验的真实语音，不分析音色、音乐或声音情绪。
- 旧版传入 `include_audio=true` 也不会发送音频。新分析禁止将对白来源标为音轨。保留旧记录与旧文件，不破坏历史数据。
- 聊天请求指纹增加输入策略版本，旧的远端会话链不再续用，新一轮从已审查的本地记录重建。视频附件只携带视频，不引用旧音频文件。
- 图片/视频生成的参考音频和数字人配音仍走各自接口，不受本次修改影响。

离线验证：69 项 Node、42 项 Python 测试；含带声视频不生成 WAV、视频与图片请求不含 input_audio、旧音频开关无效。未进行付费模型调用。
