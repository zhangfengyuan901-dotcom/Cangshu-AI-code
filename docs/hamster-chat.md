# 仓鼠AI智能体 V1（1.7.1）

独立的 `/chat/` 页面，复用本地工作台服务、内置 Python、动态端口与健康检查。主应用左侧“仓鼠智能体”打开浏览器，原有智能成片和创意工作台不变。

## 客户使用

1. 在主应用账户页保存“仓鼠智能 API Key”，保持主应用开启。
2. 打开“仓鼠智能体”。可以直接聊天，也可以上传文件或点击“我的资产”。输入 `@` 打开资产选择。
3. 附件先保存本机，发送消息后才提交云端理解。资产库文件复制到会话，不修改原资产。
4. 连续追问；生成期间显示思考状态，完整回答经审查后一次性展示并保存。可停止、复制，失败后可主动重新请求。
5. 会话支持搜索标题、重命名、移除。刷新浏览器、退出应用后，已保存记录和附件仍在。

没有联网搜索、知识库、自动工具执行，也不会自动生成或购买图片/视频。本地版不代表模型离线运行。界面统一使用仓鼠品牌，不宣称自主训练底层模型。

## 首版素材边界

| 类型 | 支持与限制 |
| --- | --- |
| 图片 | PNG/JPG/WebP，最多4000万像素 |
| 视频 | MP4/MOV/WebM，最长3分钟；单独提供同源音轨，不能把字幕当作听到的对白 |
| PDF | 文件输入，实际解析受开通模型能力限制；加密、损坏等文件可能失败 |
| DOCX | 提取段落文字，不解析嵌入图片、不保留原排版；可转 PDF 以保留视觉内容 |
| TXT/MD | UTF-8 编码 |
| 通用 | 单个50MB，每轮最多6个、合计100MB；文档最多4万字/份，一轮文档和问题合计9万字符；每会话最多60份附件 |

文件选择、拖放和图片粘贴均可使用。每份附件获得稳定的 `@素材N` 编号；再次引用已有附件不会覆盖原文件。

## 会话与响应机制

- 后端 `chat.py` 使用现有智能密钥及 Responses API；不向页面返回供应商配置、响应 ID 或原始异常。`HAMSTER_CHAT_MODEL` 为部署级覆盖项，客户界面没有底层型号选项。
- `store=true`、`stream=true`，每轮显式发送系统指令。续聊只提交本轮输入和 `previous_response_id`，不是每次上传全部历史。
- 上游仍使用流式协议，但原始文本分片不进入会话状态、页面或本地数据库。完整回答审查后才发布、保存；浏览器每500毫秒读取任务状态，页面断开不取消后台任务。
- 同一会话一次一个请求；不同会话独立。客户端请求 ID 持久去重，父消息 ID 检查防止多窗口覆盖上下文。
- 请求中断、失败、停止不保留未审查的部分回答；只有收到上游 completed 且有效文本经审查后才标记完成。重启将未完成任务标记 interrupted，不自动重发可能已计费的请求。
- 响应与临时云端文件请求3天有效期。有效续接复用云端 ID；过期、密钥或模型变化、达到20轮时重建有界上下文。
- 重建最多取最近20条消息、9万字符、12份附件；完整原记录仍在本地。界面明确提示部分恢复，不伪装成无限记忆。需要更早素材时请重新引用。
- 仅明确的 previous_response_id 参数失效拒绝允许自动重建重试一次。网络超时、流中断等不自动重复请求。文件解析权限仍需实际账户开通。

## 数据存放与安全

### 聊天身份与发布关卡（1.7.1）

- 每轮固定身份为“仓鼠AI智能体”。身份伪装、管理员/调试要求、附件指令、翻译或编码要求不能覆盖身份边界；不虚构自主训练或完全离线。
- `chat_policy.py` 对完整回答做本地规则审查：自我身份披露、内部型号/当前密钥、配置字段/服务地址和大段系统指令。规则做全半角、空格、常见零宽字符归一化。公开讨论第三方 AI 产品不做全局关键词封禁。
- 命中规则时，整条替换为固定品牌边界答复；不存违规原文，不继续使用该云端响应 ID。下轮通过本地已审查历史重建上下文。检查失败则本轮失败，不发布原文。
- 旧版完成回答在启动/回放前检查，命中内容替换为安全答复；旧的未完成分片清空。旧云端链断开以避免沿用未经审查的上下文。用户输入与原始附件不做品牌替换。
- 聊天接口按消息字段白名单返回，不返回审核内部记录、模型元数据、云端 ID、密钥或原始异常。请求禁止额外字段；校验错误不回显输入。响应设置 `Cache-Control: no-store`。
- 聊天请求上下文内的标准 Python/SDK 日志只保留固定脱敏事件，不记录请求正文、密钥和异常堆栈。接口仅返回固定错误码与本地提示；不增加原始日志/模型响应导出端点。不改变其他工作台或代理接口的行为。
- 这是身份和内部信息规则审查，不是通用内容安全分类器；不保证识别所有语义变体、特殊编码或对抗提示。便携版代码、网络连接、本地数据库可被有权限的用户检查；不构成底层实现绝对保密。旧数据库/WAL、备份及升级前已经导出的信息也不承诺安全擦除。

数据存于运行工作流目录下 `chat-data/`。桌面发布版对应应用用户数据目录的 `smart-video-agent/chat-data/`，不是临时 EXE 释放目录。

- `conversations.sqlite3`：完整会话、附件索引、请求状态与私有上下文引用。WAL + FULL 同步保证提交原子性。
- `<会话ID>/<附件ID>.<扩展名>`：会话私有附件；页面只能按所属会话访问。
- 移除操作为软删除（回收区标记），不是彻底擦除；本版无回收区 UI。需恢复时先退出应用，再备份数据库，由维护人员恢复 deleted 标记。云端内容按有效期清理。
- `chat-data/` 已排除 Git 与安装包。更新工作流不会覆盖会话数据。
- 文件内容/文件名作为不可信资料；禁止 raw HTML 渲染、远程图片自动加载、任意本地路径访问。请求使用同源与本机 Host 校验。
- 文件与会话数据库未加密，不是跨设备同步。主应用关闭后计算停止；本机已保存内容可在下次启动恢复。

## 验证

```powershell
cd smart-video-agent
.venv/Scripts/python.exe -m unittest test_chat test_creative test_studio -v
```

根目录执行 `npm test`。`scripts/qa-chat-server.py` 在 8006 提供隔离的浏览器测试页面，使用模拟模型和资产，绝不请求付费推理。

SDK MockTransport 测试验证真实 SDK 的 SSE 解码及续接请求格式；不代表真实上游的模型权限、PDF 理解质量或视频识别质量已经验收。正式使用前应使用有权处理的小素材进行实际账户验收。
