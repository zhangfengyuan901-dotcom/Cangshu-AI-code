# 创意工作台：接入点、分析模式与错误诊断（1.7.2）

账户页新增“创意工作台接入点 ID”：可填写当前智能密钥所属项目可访问的 `ep-…` 编号；留空保留默认模型。配置仅影响创意工作台，每次分析读取最新值，不修改聊天和智能成片的模型选择。

## 分析模式

- 音画联合：默认模式，上传视频和独立同源音轨。需要接入点同时接受视频、音频输入。
- 仅画面与字幕：用户主动选择的兼容模式，只向模型提供视频参考，不发送独立音轨。对白只可来自可见字幕或标为无法确认，不允许脚本把它标成音轨识别结果。结果固定显示“未识别音轨”提示。
- 不自动在失败后换模型、降级模式或重复发起可能计费的请求。

## 失败出口

页面显示原因，并可展开、复制失败步骤、本地错误码、HTTP 状态、上游请求追踪编号和本地任务 ID。该记录随任务保存，重新打开仍可查看。不复制密钥、账户号、模型名称、原始请求/响应、素材内容。

`MODEL_NOT_ENABLED` 表示指定模型未开通，区别于密钥无效；`CONTENT_TYPE_UNSUPPORTED` 表示输入模态不被接受，区别于网络问题。其他分类包括认证、权限、资源不存在、限流/额度、连接超时、输入校验和输出结构校验。上游未提供追踪编号时明确显示“未返回”。

旧版本已经丢弃的错误详情不能凭空恢复；旧任务仍保留原提示，新请求才能记录新的诊断。

## 2026-09-15 真实测试记录

经用户明确授权，使用临时测试密钥及指定接入点，对原先失败的 13.24 秒视频做了真实云端测试；不是仅使用模拟模型。

| 测试 | 实际结果 |
| --- | --- |
| 原默认模型，最小文字请求 | HTTP 404 / ModelNotOpen；账户未开通指定版本 |
| 用户接入点，最小文字请求 | completed，49 tokens |
| 用户接入点，视频＋独立音轨（两次定位） | HTTP 400 / InvalidParameter / input.content 不支持该内容类型；上传、解析完成，失败在推理请求 |
| 用户接入点，仅视频隔离探测 | 成功返回6个分镜，15,753 tokens |
| 用户接入点，单独音频 Data URI | HTTP 400 / 不支持该内容类型 |
| 修改后的正式分析逻辑，仅画面模式 | 成功返回7个分镜，通过结构及时间轴校验，16,478 tokens |

成功请求合计返回32,280 tokens（不是金额估算，实际费用以服务账单为准）。云端测试临时文件的删除均未报告失败；原始视频和用户资产没有修改。测试输出位于被 Git/安装包排除的 `output/creative-live-report.json`，不含测试密钥。

此接入点通过了视频画面分析，**没有通过独立音频或音画联合模式**。模型输出仍可能有识别误差、估计时间戳和不准确字幕，用户需要人工核对。未将测试接入点硬编码给所有客户，未将临时密钥写入源码或正式配置。

维护脚本 `scripts/probe-creative-live.py` 只从进程环境读取 `HAMSTER_LIVE_TEST_KEY`；`HAMSTER_CREATIVE_MODEL` 可指定测试接入点。显式运行才调用付费推理，无自动重试。普通单元测试不调用真实模型。
