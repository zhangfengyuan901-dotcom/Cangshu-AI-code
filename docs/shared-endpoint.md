# 1.7.3 统一智能服务配置

账户页一次保存「仓鼠智能 API Key」和「统一推理接入点 ID」。配置了接入点时，仓鼠智能体、智能成片的七个编排阶段及媒体评估工具、创意工作台的分析与提示词生成均使用它。图片/视频生成仍使用原来的独立 Key 和线路。

- 接入点为当前 Key 可访问的 `ep-…` 编号，不能填写网址。留空保留旧版默认模型行为；建议明确填写已开通的多模态接入点。
- 旧 `creativeEndpointId` 自动作为共享配置读取，下次保存迁移为 `llmEndpointId`；明确清空新字段不会恢复旧值。
- API Key 输入留空时保留服务器已保存的 Key。无效接入点会拒绝整次保存，不会只替换 Key。
- 聊天每轮、创意每次模型请求、智能成片每个新任务读取配置，无需重启；已进行中的请求不切换。聊天更换 Key 或接入点后，不再携带旧远端会话 ID，而从已审查的本地记录重建上下文。
- 共用接入点不增加模型能力。全功能使用需要相应的图片/视频理解、工具调用等支持；不支持音频的接入点仍须使用创意工作台的仅画面模式。
- 配置接口只返回接入点及配置状态，不返回 Key；聊天发布/保存前继续执行原有审查。

验证：69 项 Node 测试、41 项 Python 离线测试；覆盖旧配置迁移、无效输入原子拒绝、清空、聊天切换接入点重建上下文、成片七阶段及评估工具路由。未调用付费模型。
