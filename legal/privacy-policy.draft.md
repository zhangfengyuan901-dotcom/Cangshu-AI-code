## 二、我们处理的信息

### 1. 账户与验证信息

- 注册邮箱、用户名、加密后的密码凭证；
- 邮箱验证码、密码重置和登录安全记录；
- 如您申请企业认证、开票或退款，可能需要的主体、联系人、支付和发票信息，具体范围：`【待填写】`。

### 2. API 令牌与使用记录

- 令牌名称、令牌哈希或掩码、所属分组、模型权限、创建与最后使用时间；
- 请求时间、模型、请求编号、输入/输出用量、计费金额、状态码、耗时和任务状态；
- IP 地址、User-Agent、设备/网络和异常行为特征等安全日志。

我们不会在页面或日志中显示完整 API 令牌。生产环境是否持久化提示词、上传文件或模型输出：建议默认不持久化正文，`【待确认实际实现】`。

### 3. 充值、账单与客服信息

- 订单号、金额、支付状态、退款状态和支付渠道返回的必要交易标识；
- 消费明细、余额变动和发票信息；
- 您主动提交的工单、邮件、问题描述和附件。

我们不应直接保存完整银行卡号或支付密码；支付机构实际处理范围需在接入后补充。

### 4. Cookie 与安全验证

我们使用必要的会话 Cookie 维持登录，并使用 Cloudflare Turnstile 判断请求是否可能来自自动化程序。必要 Cookie 不用于跨站广告。Cookie 名称、期限和具体用途：`【上线前按实际配置补充】`。
