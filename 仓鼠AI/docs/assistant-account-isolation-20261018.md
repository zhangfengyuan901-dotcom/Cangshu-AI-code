# 智能体账户隔离改造（内部，2026-10-18）

本说明对应全量适配方案第四节。仅修改源码与离线回归，未部署 Worker、未打开 PIKNO 智能体开关、未提交真实推理。最终验收由人工执行。

## 执行身份

- PIKNO bridge 提供随机 opaque `scope` 与配置 `revision`。同账户换 Key 保留 scope；任一配置修订使正在执行的旧请求失效。Python 只读取本机 `/api/inference/context` 的 scope、revision、configured，不接收客户 Key 或真实账户 ID。
- Python 在用户提交时捕获配置，通过锁定 SDK 支持的独立 HTTP client 固定 scope/revision 请求头，并关闭环境代理继承。上传、解析轮询、回答提交与发布前重新核对；SSE 事件的核对在 100 ms 内合并。云端文件与上下文的缓存指纹包含 scope，账户切换清除云引用并保留本地聊天、附件及文本。
- Node 在每个请求开始验证 scope/revision，捕获当时 Key。后续步骤仅验证原配置，不能改用新账户 Key。配置变化后最多一个 50 ms 检查周期中止正在转发的文件或回答流；旧激活结果不再用于提交。
- 中止本地流不能撤销云端已经接受的回答，不声称取消计费，也不自动再次发送。

## 云对象授权

- Worker 对文件 ID 与回答 ID 发放 AES-GCM 加密对象句柄，含版本、账户身份、对象种类及原始 ID。密钥从现有 Worker Secret `TOKEN_SIGNING_KEY` 做用途隔离派生。无须新增客户数据库或把推理密钥写入 D1/KV/R2。
- 新 PIKNO 短会话按经签名的真实账户 uid 授权，同账户换 Key 不丢失对象权限；旧会话无法证明共同 uid，只按旧凭据摘要隔离。
- 文件 GET/DELETE、请求中的 `file_id` 与 `previous_response_id` 在任何上游调用之前解密并验证归属。另一账户返回 403；裸 ID、伪造句柄或对象种类不符返回 400。JSON 与 SSE 返回的云文件/回答 ID 均转换成账户句柄。
- 只有上游明确 400/404、结构化引用参数属于白名单且没有已受理标记时，才返回固定的 `object_reference_rejected` 和 `not_submitted`。上游错误正文不透传。未知结果、5xx、已开始 SSE 的错误均不能产生重建信号。同账户授权后的文件 DELETE 204 保留空响应，仍先验证对象归属。
- 当前聊天协议只支持本地消息重放与账户文件句柄。`item_reference`、输入对象 `id`、文件数据/URL 的替代引用、共享会话、模板及非空工具列表没有归属协议，因此拒绝，不向上游透传。现有客户端附件均使用 `file_id`，不受影响。
- PIKNO 代理必须允许最长 2048 字符的文件句柄，仅放宽原文件对象路径的长度，保留认证、方法和路径限制。

## 升级与恢复边界

- 新客户端使用 `visual-v2` 指纹并在首次使用旧对话时断开原云缓存；本地资料仍可在用户主动发送时重建。旧裸云对象不能迁移为新授权句柄，不允许凭原始 ID 绕过检查。
- 仅确定未提交的失效 `previous_response_id`（400/404）允许按现有规则重建一次上下文。跨账户 403、网络不明、流中断均不自动重发。已明确拒绝的文件引用从缓存中分离，留待下次用户明确请求时重新准备。
- Worker 签名 Secret 轮换会使旧句柄失效；不可恢复的旧云对象不能宣称已自动取回。本地记录及文件不删除。
- `assistant_disabled` 以固定错误码穿过本机代理，聊天显示“仓鼠智能服务尚未开放”。连接检查仍只执行激活，不执行收费推理。

## 离线回归与人工验收

自动回归覆盖：同账户换 Key；双账户文件读删、回答引用与续接；伪造/裸 ID、未知引用变体；上传前、上传中、解析轮询、回答提交及 SSE 期间切换配置；旧请求固定原 Key；本地资料保存；服务未开放提示。

实际锁定 Python SDK 的组合回归通过 loopback HTTP 接入 Worker，使用模拟上游验证：初始 SSE 回答成功、失效上下文 404 后仅安全重建一次、连接结果不明与 SSE 中断各只提交一次。组合测试同时验证 SDK 的 nullable 参数按“未提供引用”处理，并验证 scope 请求头实际出现在 HTTP 请求中。没有连接真实上游。

人工验收前先保持智能体关闭，审核候选 Node/Python/Worker 与 PIKNO 代理版本配套。部署、配置真实 Secrets、开启服务及真实上传/推理须另行安排。人工最终验收应使用两个人工测试账户，验证云文件与回答不能跨账户使用，并核对同账户 Key 轮换、浏览器刷新、进程重启和本地历史恢复。真实请求须核对服务记录和费用，离线模拟不代表生产验收通过。
