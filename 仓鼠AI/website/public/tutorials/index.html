1. 连接账户并充值

  1. 从应用打开中转站

    进入仓鼠AI「账户」，点击「去中转站充值」。系统浏览器会打开中转站。新用户注册并完成安全验证后自动登录；已有账户可直接登录，原账户、余额与订单继续使用。

  2. 首次连接当前仓鼠AI

    核对网页与应用显示的连接码一致，再点击「连接仓鼠 AI 并继续充值」。系统按账户与用途补齐应用 Key，并在本机加密保存。已有同账户的有效配置继续使用。网页账号与应用账号不一致时，请切换网页账号后继续。

  3. 在网页按需充值

    核对充值到账账号，选择金额和支付方式，点击「充值」进入收银台。按收银台显示金额付款。付款成功后网页核对到账并更新余额，取消或付款状态未确认时请查询原订单，避免重复付款。

  4. 手动返回应用开始使用

    回到仓鼠AI后，账户页自动读取中转站余额和本机连接状态。点击「检测连接」可免费核对功能配置，检测不创建生成任务、不扣费。账户首次连接尚未完成时，请按应用提示重新核对；已经付款的订单继续由中转站查询处理。

图片、视频、工具与对话用途共用同一账户余额。数字人与黑白深度使用工具用途。Key 在本机受系统加密保护；手动更换和移除仍可在高级连接设置中操作。切换账户时，请先处理旧账户的本机配置，再连接新账户。

连接检测通过表示认证及当前可用线路已确认。生成结果与费用以实际任务和账户记录为准。右上角素材权限灯按当前功能分别检测，手动检测需要遵循页面显示的重试间隔。

2. 选择线路并生成

  1. 选择已开放的线路

    生成页和画布显示中转站发布的线路。打开的生成页和画布会接收线路变更通知，可见时每 60 秒刷新作为兜底。已下架线路从可选列表移除；原选择保留并提示不可用，禁止生成，不会静默切换线路。按线路提供的尺寸、画质、时长和比例选择。

  2. 检查参考素材上限

    页面显示各类素材的有效限制和合计上限。图片生成支持最多 5 张参考图，并提供 4:3、3:4 比例。视频生成按当前线路分别限制图片、视频、音频数量及合计数量，以页面显示为准。超限请先减少素材，再上传或报价。视频和音频上传前会读取实际时长；无法读取的素材需重新选择。生成前会检查素材有效期，并在需要时重新上传仍可读取的本地素材；请等待上传完成。

  3. 点击生成

    图片生成不展示固定预估价，由中转站核对余额并按实际用量结算。视频和工具在提交前获取中转站当前报价并核对余额。余额不足时可前往充值。报价过期或参数变化时，按提示重新获取报价。

工作台和画布按目标功能处理素材。视频生成的参考素材上传到中转站素材服务。图片参考图随生成请求直传，数字人和黑白深度素材直接上传到对应工具服务。图片和工具结果从上游下载到本机，任务状态由后台保存。结果下载失败时恢复原任务的下载，勿为取回结果重复生成。

3. 停止剩余份数与查询历史

选择 2 份或 4 份后，每份单独提交。点击「停止剩余」只阻止尚未发送的份数；已发送任务继续按原记录查询，不表示任务取消或已退款。刷新和重启不会自动继续剩余份数。

出现「提交待确认」时，请在历史记录核对原任务，勿重复生成。清除已结束记录仍保留未知任务。没有任务编号时暂不保证自动找回；保存失败与生成失败分开，不能为下载结果重新生成。余额不足时可通过提示中的「前往充值」进入账户中心，按需选择充值金额。

同账户且有读取权限的有效 Key 可查询历史工具任务。历史线路名称和报价快照保留；报价是预计费用，实际扣费以账户记录为准。结果完成后保存本地，临时链接过期不保证可以恢复。

4. 画布与对话

画布支持现有文本、素材、上传、图片、视频、数字人、深度和 Output 节点。连接输入，选择线路和参数后手动执行当前节点。生成费用由中转站结算，下游节点需单独执行。旧节点、连线和已绑定结果保留。

首次连接会自动配置对话用途，已有用户沿用同账户的对话 Key。对话仅使用豆包 Seed 2.1 Pro，由 PIKNO 中转站按实际 Token 用量结算。当前新对话支持文本。各项功能的计费价格以 PIKNO 中转站为准，实际扣费以账户账单为准。停止回答不代表免费或退款；异常请求转后台待查后可继续发送新消息，原请求不会自动重发。点击左上角仓鼠标志单独检测对话连接；灰色表示尚未成功连接，彩色仅表示本次检测成功。提示「尚未开放」时等待服务开放，无需反复更换 Key。

换账户后会断开旧云端素材与回答链的关系，本地聊天、附件和历史文字保留。旧版改写工作台数据与导出结果保留；当前视频反推使用独立入口。

5. 视频反推

先启用工具 Key，再进入「视频反推」。可上传本地视频，也可切换「粘贴链接」，粘贴抖音、小红书或哔哩哔哩的视频分享链接。分享文案中只能包含一个受支持的视频链接；其他网站或多个链接不会提交。

本地视频限 500 MiB、最长 600 秒。链接模式直接提交受支持的视频链接，无需先手动下载视频。

每次提交前，请确认中转站显示的按秒价格和预占金额。成功后按实际计费秒数结算并释放差额；失败释放预占，结果未知时保留预占并只查原操作，不重复提交。实际费用以账户记录为准。

任务完成后可复制提示词；反推记录按当前账号保存。切换账号后，先核对身份再开始新的任务，旧任务和结果保留。
