# 创意工作台 V1

从主应用侧栏「创意工作台」打开 `http://127.0.0.1:8000/creative/`。
与智能成片共用一个本地服务，互不代替；不再调用旧视频反推工作流。

## 配置与边界

- 读取主应用已保存的「仓鼠智能 API Key」，不使用图片视频服务或工具服务密钥。
- 默认音画模型 `doubao-seed-2-0-lite-260428`。需要在方舟账户开通该模型；密钥相同不代表有模型权限。
- 可用环境变量 `HAMSTER_CREATIVE_MODEL` 指定另一个已验证支持图片、视频和音频输入的模型或接入点。不要改成仅视觉模型，否则不能识别音轨对白。
- 原视频及其同源 WAV 音轨通过 Ark Files 上传，Responses 分析。输入视频2fps采样，音轨单独输入以明确提供声音；没有音轨时不推断口述对白。不使用第三方 ASR Key，也不要求用户配置对象存储。
- API 请求 `store=False`，任务后尝试删除这次上传的云端临时文件，删除未确认会在界面提示。不能等同于供应商零留存承诺。
- 选择、上传按钮先保存本地；「自动拆解」和「生成 Prompt」会发送相应素材/脚本到智能模型并按实际用量计费。不会自动重试计费请求。
- V1输入 MP4/MOV，最大50MB、180秒；替换素材为最多9张图片，每张10MB。达人、场景分别绑定；产品可选。
- 目标5/10/15秒为改编时长，不是对原片的逐帧复刻。具体生成线路的时长/素材支持仍以主生成页为准。

## 数据与使用

工作记录和原片位于工作流目录的 `creative-data`；打包排除该目录。
最终方案保存在「仓鼠AI生成结果 / 创意工作台」，包含素材绑定顺序、设置与分镜 Prompt。
界面支持历史恢复、停止、对白来源核对、时间轴定位、JSON脚本修正、资产库/临时图片替换、素材下载与Prompt复制。
历史原视频反推结果仍在主应用历史记录中，本次不迁移或删除。

原片/素材中的文本不是系统指令。输出使用结构校验限制角色引用、场景引用、时长、分镜顺序和素材编号；AI内容仍可能有识别误差，发布前需要人工核对。
