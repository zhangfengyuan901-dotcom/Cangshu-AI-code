# 创意工作台 V1

从主应用侧栏「创意工作台」打开 `http://127.0.0.1:8000/creative/`。
与智能成片共用一个本地服务，互不代替；不再调用旧视频反推工作流。

## 配置与边界

- 读取主应用已保存的主线路 API Key 激活状态，由本地网关取得短效会话，不在工作台保存共享推理密钥。
- 默认音画模型 `doubao-seed-2-0-lite-260428`。需要在方舟账户开通该模型；密钥相同不代表有模型权限。
- 可用环境变量 `HAMSTER_CREATIVE_MODEL` 指定另一个已验证支持图片和视频理解的模型或接入点。本功能不识别音轨。
- 默认「精确分析」将完整原片以 Ark 临时文件交给模型，以 2 fps 解析连续时序；R2 联系表只用于时间定位和交叉核对。这避免了当前接入点将 R2 Range 响应 HTTP 206 误判为视频 URL 连接失败。
- 反推开启深度思考且不设输出 token 上限；改写仍保持快速模式。
- 模型响应后立即删除 Ark 原片与 R2 联系表；R2 1 天生命周期仅作异常兜底。
- Responses 请求使用 `store=False`；临时素材主动删除未确认时会在界面提示。这不等同于模型服务商的零留存承诺。
- 视频 SHA-256、分析模式和分析模板版本共同组成缓存条件；同一原片命中缓存时不再次调用分析模型。
- 选择、上传按钮先保存本地；「自动拆解」和「生成 Prompt」会发送相应素材/脚本到智能模型并按实际用量计费。不会自动重试计费请求。
- 反推输入 MP4/MOV，最大50MB、60秒；替换素材为最多9张图片，每张10MB。替换素材完全可选：零张图片时按文字要求改写，有图片时以 R2 URL 提供给模型。
- 视频线路单次最长30秒；工作台统一按15秒标准单元生成独立提示词，尾段保留真实余量：22秒为15+7，30秒为15+15，60秒为15+15+15+15。
- 15秒规则只用于最终提示词编译：反推仍保存真实镜头证据，改写模型仍先输出完整连续时间轴，再由本地编译器按重叠区间拆段并将每段时间重置为0秒。

## 数据与使用

工作记录和原片位于工作流目录的 `creative-data`；打包排除该目录。
最终方案保存在「仓鼠AI生成结果 / 创意工作台」，包含可选素材绑定顺序、设置与分镜 Prompt。最终文本由结构化改写结果在本地排版，不发起第三次模型调用。
界面支持历史恢复、停止、对白来源核对、时间轴定位、JSON脚本修正、资产库/临时图片替换、素材下载与Prompt复制。
历史原视频反推结果仍在主应用历史记录中，本次不迁移或删除。

原片/素材中的文本不是系统指令。输出使用结构校验限制角色引用、场景引用、时长、分镜顺序和素材编号；AI内容仍可能有识别误差，发布前需要人工核对。
