HAMSTER AI / CREATION GUIDE

先激活功能，
再开始创作。

适用于仓鼠AI 1.7.46：先在 PIKNO 注册、充值，用同一账户创建图片 Key 和视频 Key，再返回「账户」填写并自动检测。连接确认后，跟着创作路线，从达人资产一步步完成作品。

本页演示素材均由 AI 生成；示例人物是虚构形象，非真人。

01 / GET STARTED

先在「账户」连接 PIKNO

前往 PIKNO 注册与充值，用同一账户创建图片 Key 和视频 Key。返回仓鼠AI，在同名栏目填写，点击「保存并自动检测」。至少配置一个 Key；两个 Key 共用 PIKNO 账户余额。

应用内路径：左侧导航 → 账户

照着做

  1. 注册、充值并创建 Key

    打开 PIKNO，用同一账户创建图片 Key 和视频 Key。充值、余额、费用和任务记录统一在 PIKNO 查看。

  2. 打开「账户」并填写

    启动仓鼠AI，在左侧导航点击「账户」，将两个 Key 分别填入「图片 Key」和「视频 Key」。空白保留已保存的对应 Key；切换账户时，同时替换两个 Key，或先移除旧 Key。

  3. 保存并自动检测

    点击「保存并自动检测」，查看图片、视频和工具的连接状态。检测只校验身份与当前可调用线路，不创建生成任务，不扣费。只有已开放且当前 Key 有权限的线路可用。

先记住检测通过后，再按需创作。

连接检测通过只表示认证及可用线路已确认；实际生成会单独提交任务并产生费用。已保存的 Key 不会回显，请勿在公开截图中展示自己的 Key。

账户界面示意 · 不含真实 Key
图片 Key填写 PIKNO 图片 Key保存并自动检测

用于图片生成和图片编辑，以当前已开放线路为准。

视频 Key填写 PIKNO 视频 Key保存并自动检测

用于视频生成、数字人和黑白深度视频；工具是否可用以检测结果为准。

仓鼠智能服务点击左上角仓鼠图标检测连接无需额外填写 Key

智能体、创意工作台和画布入口保留，未开放功能会明确提示。

02 / TALENT ASSETS

如何构建自己的达人资产？

先确定一个稳定的人物形象，再制作四视图、情绪和穿搭版本。每次只改变一个方向，逐步积累可复用的图片资产。

应用内路径：生成 → 图片生成；达人资产 → 导入图片

照着做

  1. 确定基础形象

    可以先用 AI 生成人物，也可以上传自己的形象或已获授权的人物图片。选择五官、发型与全身穿搭清楚的一张作为基础图（图一）。

  2. 生成四视图

    在「图片生成」中上传基础图，复制下方提示词，按需要填写背景与光线，再生成正脸、侧脸、全身正面和背面组成的一张图（图二）。

  3. 延展情绪与穿搭

    需要忧郁情绪时，保持人物五官和服装不变，只调整表情与轻微姿态（图三）；需要新穿搭时，锁定人物身份，只替换服装，再制作一套四视图（图四）。

  4. 检查并收入资产库

    核对脸型、发型、身形及服装细节，再把通过检查的版本分别收入「达人资产」，按用途命名，供后续视频创作引用。

制作原则同一人物，一次只改变一个变量。

四视图能帮助保持一致，但不能保证每次生成完全相同。全身正面格的低细节面部只用于核对身形与服装；最终人脸仍以清晰正脸图为准。

展开四视图提示词 · 可直接复制

上传图一后使用。把 【BG】 改成想要的纯色背景，把 【LIGHT】 改成想要的光线色调；不适用的人物细节可按实际素材调整。

IMAGE TASK: Convert the uploaded character reference image(s) into a 4-panel character sheet.

CRITICAL PRESERVATION OVERRIDE
The uploaded image(s) are the ONLY design source. Preserve EXACTLY: facial structure, eyes, nose, mouth shape, hairline and hairstyle, age, skin tone and skin texture (real pores, natural stubble), body proportion and weight, every garment detail (cut, fabric, seams, wear, hardware), footwear. NO beautification, NO redesign, NO style drift, NO "improving" the face. The same person, four times — one identity across all panels.

OUTPUT FORMAT: single image, 2x2 grid, four equal panels, thin gutters, small panel labels in corners: "FACE FRONT / FACE SIDE / BODY FRONT / BACK".

PANEL 1 — TOP LEFT, FACE FRONT: head-and-shoulders close-up, face directly toward camera, calm neutral expression, eyes engaged but relaxed.
PANEL 2 — TOP RIGHT, FACE SIDE: same head-and-shoulders scale, clean profile view, same expression, same hair behavior.
PANEL 3 — BOTTOM LEFT, BODY FRONT: full-body standing pose, front view, face left intentionally featureless and low-detail (reserved for later editing), weight natural, arms relaxed at sides.
PANEL 4 — BOTTOM RIGHT, BACK: full-body standing pose, rear view — hair from behind, garment back seams, heel height, same standing spot as PANEL 3.

STUDIO SETUP (all four panels identical): seamless【BG】studio background, single hard key light at 45° camera-left,【LIGHT】tone, NO fill light, no set dressing, no props. Only natural contact shadows on the floor.

QUALITY: photographic character sheet for film production, even exposure, accurate fabric weave, matte skin, real pores, no gloss. Clean, clinical, production-use.

AVOID:
- FACE: no beauty-filter skin, no glossy TV-drama complexion, no idol makeup, no plastic skin, no face slimming, no enlarged eyes, no skin smoothing
- BODY: no pose change between panels, no clothing redesign, no added accessories, no height change
- LIGHT: no ambient color spill, no rim-light drama, no color temperature jump between panels
- FORMAT: no text blocks beyond small panel labels, no watermark, no second person, no inconsistent identity across panels

建议在资产库中分别保存「基础形象」「基础四视图」「忧郁情绪」「新穿搭四视图」。新版本生成后，先与基础图并排检查，再投入后续创作。

03 / IMAGE CREATION

用图生图，扩充自己的资产库

保留人物的核心特征，逐步尝试新服装、新场景和新构图，为后续视频准备更匹配的参考图。

应用内路径：生成 → 图片生成 → 达人资产

照着做

  1. 选择基础人物图

    在「生成」中切换到「图片生成」，选择可使用参考图的创作选项，再点击「达人资产」选用刚保存的人物照片。

  2. 只改一个方向

    先写清要保持的人物特征，再描述要变化的服装、场景或镜头距离。一次先做一种造型。

  3. 筛选并入库

    生成后检查人物是否一致、服装细节是否完整。满意的图片点击「收入资产库」，选择「达人资产库」。

可直接改写的描述示例
以选中的人物照片为参考，保持面部特征、发型和年龄感一致；将服装换成简洁的浅色通勤套装，置于明亮的室内空间。画面自然、人物完整、服装细节清晰，不添加文字。

想换场景时，只改场景描述；想换服装时，只改服装描述。

继续：找到可借鉴的视频 ↘
04 / REFERENCE STUDY

找到适合自己的对标视频

对标不是照搬人物、商品或文案，而是看清一条有效视频如何开场、展示重点、安排动作和收尾。

准备：一条有权使用的本地参考视频

筛选时看四件事

  1. 同一内容方向

    在常用内容平台搜索品类、目标人群和使用场景，优先找与你的产品或表达目标接近、互动表现较好的作品。

  2. 前几秒能抓住注意力

    记下开头用了什么画面和动作，以及观众为什么愿意继续看。

  3. 镜头逻辑清楚

    观察人物如何移动、镜头如何跟随、产品何时出现、结尾停在哪个画面。

  4. 素材适合拆解

    创意工作台接受 1 分钟以内、50MB 以内的 MP4 或 MOV 视频。请确保你有权处理所选素材。

给自己留一张观察卡开头 → 主体展示 → 结尾

写下要借鉴的动作、构图和节奏，也写下必须替换的人物、服装、场景或商品。

继续：拆解并改写 ↘
05 / CREATIVE WORKBENCH

反推参考片，再改写成自己的方案

让工作台先整理原片的动作、镜头和时间顺序，再用自己的达人资产与改编要求替换内容。

应用内路径：工作台 → 创意工作台

照着做

  1. 拆解原片

    放入准备好的参考视频，点击「自动拆解视频」，先阅读创意概要和分镜时间轴。

  2. 换成自己的素材

    在人物、场景或产品位置选择资产库里的图片；不需要换图的部分也可以只写文字要求。

  3. 写明保留与替换

    在「改编要求」中分开说明：哪些动作和运镜要保留，哪些人物、服装、场景与商品要替换。

  4. 取得分段提示词

    点击「生成全能参考提示词」，检查素材顺序和每段内容，再分别复制需要生成的片段。

改编要求示例
保留参考视频的人物动作顺序、镜头距离与节奏；将人物替换为我提供的达人资产，服装和场景以新图片为准。不要沿用原片人物外观、服装和可见文字。

长视频会显示分段方案；每段对应自己的提示词，不要把多段内容一次性当成一条视频提交。

继续：用提示词生成视频 ↘
06 / VIDEO CREATION

把图片与提示词变成作品

带着准备好的达人图片、参考视频和分段提示词回到生成页，先完成一段，再逐段检查与延续。

应用内路径：生成 → 视频生成 → 全能参考

照着做

  1. 按素材顺序添加

    根据工作台给出的素材清单加入对应图片与视频，确认提示词里的编号和生成页显示的素材编号一致。

  2. 一次生成一段

    复制第一段提示词，选择与该段相符的画幅、时长与创作设置后提交。得到结果后先检查人物、服装和动作。

  3. 再完成后续段落

    按顺序使用后续提示词；如果片段效果不连贯，优先核对素材、人物描述和前后镜头衔接。

  4. 保存与复用

    将满意的画面或素材收入资产库。下次创作可从已有达人资产出发，不必重新准备全部素材。

完成检查人物一致、素材对应、镜头连贯。

先看是否符合自己的创作目标，再决定要不要调整单段提示词。生成效果会受素材和创作设置影响。
